Условия использования

Smena Manager предназначен для внутренней совместной работы приглашённой команды.

1. Доступ

Использовать сервис могут только пользователи, которых администратор добавил в список доступа. Пользователь отвечает за безопасность своего Google Account и не должен передавать другим лицам резервный идентификатор доступа.

2. Допустимое использование

Нельзя использовать сервис для незаконных действий, распространения вредоносных файлов, нарушения прав третьих лиц, обхода ограничений доступа или вмешательства в работу инфраструктуры.

3. Командный контент

Пользователь сохраняет права на добавленный им контент и предоставляет Smena Manager техническое разрешение обрабатывать его только для работы функций сервиса. Участники должны загружать материалы, которыми имеют право делиться с командой.

4. Внешние сервисы

Для работы используются Google Sign-In, Google Drive, Gmail API, Vercel и службы push-уведомлений браузеров. Их работа также регулируется условиями соответствующих поставщиков.

5. Доступность и изменения

Сервис предоставляется в текущем виде для внутренней работы команды. Функции могут обновляться, а доступ может временно ограничиваться для обслуживания, безопасности или устранения сбоев. Существенные изменения этих условий публикуются на этой странице.
