Политика конфиденциальности

Эта политика объясняет, какие данные обрабатывает Smena Manager, зачем они нужны и как пользователь может управлять ими.

1. Какие данные обрабатываются

  • данные профиля разрешённого участника: имя, подтверждённый адрес электронной почты, роль и команда;
  • рабочие данные: проекты, задачи, комментарии, знания, закладки, файлы, настройки и журнал действий;
  • технические данные: сессия входа, версия синхронизации, push-подписка браузера и диагностические ошибки;
  • настройки доставки уведомлений по электронной почте и в браузере.

2. Данные Google

Google Sign-In передаёт приложению идентификатор, имя и подтверждённый email, чтобы сопоставить пользователя с разрешённым профилем. Рабочая база и загруженные командой файлы хранятся в Google Drive аккаунта владельца рабочего пространства.

Для почтовых уведомлений Smena Manager запрашивает минимальную область доступа https://www.googleapis.com/auth/gmail.send. Она используется только для отправки уведомлений о назначениях, комментариях, упоминаниях, сроках и выбранных пользователем сводках. Приложение не читает, не изменяет и не удаляет существующие письма, контакты или настройки Gmail.

Использование и передача информации, полученной через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

3. Цели обработки

Данные используются для аутентификации, совместной работы в задачах и проектах, синхронизации файлов, доставки выбранных уведомлений, обеспечения безопасности, резервного копирования и восстановления работы сервиса.

4. Хранение и защита

Рабочие данные и вложения хранятся в выделенной папке Google Drive. OAuth refresh-токены и ключи доставки хранятся как серверные секреты и не передаются в браузер. Сессии подписываются, изменения версионируются, а права администратора, редактора и наблюдателя проверяются на сервере.

5. Передача третьим сторонам

Smena Manager не продаёт пользовательские данные и не использует их для рекламы. Данные передаются только поставщикам инфраструктуры, необходимым для работы функций: Google (вход, Drive и Gmail), Vercel (хостинг) и push-сервису выбранного браузера. Доступ других участников ограничен их ролью и составом рабочего пространства.

6. Срок хранения и удаление

Рабочие данные хранятся, пока используется пространство, либо до удаления администратором. Пользователь может отозвать доступ Google в настройках своего Google Account и отключить email/push-уведомления в Smena Manager. Для удаления профиля или связанных данных обратитесь по адресу ниже.

7. Контакты и изменения политики

Вопросы, запрос на доступ или удаление данных: avdeevandry1999@gmail.com. При существенном изменении способов использования данных политика будет обновлена до применения новых целей обработки.

English version

1. Data we process

Smena Manager processes approved members' names, verified email addresses, roles and teams; workspace projects, tasks, comments, knowledge, bookmarks, files, settings and activity; signed session and synchronization data; browser push subscriptions; and each member's notification preferences.

2. Google user data

Google Sign-In supplies an identifier, name and verified email address to match a person to an approved profile. Workspace data and team uploads are stored in the workspace owner's Google Drive account.

For email notifications, Smena Manager requests only https://www.googleapis.com/auth/gmail.send. It is used to send assignment, comment, mention, deadline and optional digest notifications selected by users. The application does not read, change or delete existing email, contacts or Gmail settings.

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

3. Purpose, storage and security

Data is used for authentication, team collaboration, file synchronization, selected notifications, security, backup and recovery. Workspace content is stored in a dedicated Drive folder. OAuth refresh tokens and delivery keys are server-side secrets and are never sent to the browser. Sessions are signed, updates are versioned, and roles are enforced by the server.

4. Sharing

We do not sell user data or use it for advertising. Data is shared only with infrastructure providers needed for these functions: Google for identity, Drive and Gmail; Vercel for hosting; and the push service of the selected browser. Other team members' access is limited by workspace membership and role.

5. Retention, control and contact

Workspace data is retained while the workspace is in use or until an administrator deletes it. Users may disable email and push notifications, revoke Google access in their Google Account, or request profile and related data deletion by contacting avdeevandry1999@gmail.com. Material changes to Google data use will be disclosed before the new use begins.
