## Границы реализации

- Google Drive копирование выполняется на стороне провайдера, без чтения видео целиком в память функции. Независимая копия находится **в том же Google-аккаунте**, расходует дополнительную квоту и не заменяет внешнюю резервную копию.
- Копируются только выбранные бинарные файлы, не всё пространство. Подготовка продолжается, пока вкладка выполняет запросы; закрытие/фон может потребовать «Продолжить копирование». Серверная lease и детерминированное имя делают повтор безопасным.
- До 500 файлов в партии; до четырёх наборов на аккаунт и 16 на пространство. Автоматическое удаление/срок хранения и UI удаления наборов пока отсутствуют: копии остаются. Операции создания/продолжения/восстановления повторно проверяют актуальное членство и права проектов.
- Текущий UI восстановления использует серверную запись набора в `_mediaBackups`; отдельный манифест можно скачать, но его загрузка для восстановления после полной утраты core ещё не реализована. Низкочастотный путь резервирования пока читает полный workspace/catalog; это не продолжение прежних оптимизаций всех служебных чтений.
- Группы графа относятся к загруженному окну, не обещают единовременную загрузку всего каталога. Таблица заметок использует уже загруженный knowledge-документ. Резервный recovery bundle по-прежнему ограничен **100 MiB бинарных вложений**; новая независимая копия — отдельная операция.
- Виртуальные 20 GiB, 10,000 узлов/заметок/уведомлений и 500 путей — регрессия алгоритмов, не реальная пропускная способность production. Реальные Safari/iOS, Android Chrome, блокировка экрана, возобновление многогигабайтной передачи, второй Google-аккаунт и screen reader остаются **непроверенными**. Доступных телефонов пользователь пока не предоставил.
- Случаи нестабильного IAB (несвоевременный снимок, ошибка динамического чанка старой сборки, отказ захвата) отделены от успешных сценариев. Обновление приложения восстановило актуальные чанки без сброса Google-сессии. Локальный Chrome временно перестал отвечать в конце; эта часть не объявлена полной browser-сертификацией.

Локальные доказательства: `output/m12-acceptance/`, `output/m12-*-final.log`, `output/m12-*-complete.log`. Сырые UI-снимки и манифест с внутренними ID в Git не включены.

Physical iOS/Android, screen lock/background recovery, real multi-gigabyte throughput/recovery, a second live Google account and screen-reader acceptance remain unverified; synthetic large-data tests are not evidence of them.
