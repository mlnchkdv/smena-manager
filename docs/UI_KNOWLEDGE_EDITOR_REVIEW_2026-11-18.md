# Аудит базы знаний и мобильного редактора

18 ноября 2026. Исходная авторизованная версия smena.team: `a317a21e`.

## Осмотр опубликованного пространства

Проверены каталог заметок, чтение длинной заметки, меню действий,
свойства, пустая история версий и переход в редактор. Размеры:
1366×768, 320×567, 390×844 и 390×320. Рабочие заметки не изменялись.

Каталог, чтение и свойства помещаются по ширине. Шапка чтения на телефоне
занимает 49 px; свойства показывают поля шириной 278 px и кнопки высотой
44 px. Меню действий на коротком экране ограничивает высоту и прокручивается.

В редакторе на 320×567 панель управления занимала **116,4 px**:
переключатели чтения/редактирования и формата, отдельный ряд инструментов
и строка сохранения. Формат Markdown отображался обрезанным как «Markdo…».

## Компактная панель редактирования

На ширине до 640 px выбор формата представлен значком текущего режима
с раскрытием полного списка. Markdown и «Блоки» остаются доступны одним
действием. Полное название формата сохраняется в доступном имени кнопки
и её подсказке; значок меняется вместе с выбранным режимом.

Основные инструменты теперь помещаются в один ряд, строка сохранения
остаётся под ними. На 320 px высота панели составляет **68,4 px**,
освобождая **48 px** для текста. Кнопки имеют размер не менее 44×44 px.
На ноутбуке сохраняется текстовое название формата. Обычный текст
сохраняет свой редактор без выбора неподдерживаемых форматов.

## Сообщение о конфликте синхронизации

В отдельном синтетическом сценарии конфликта длинные кнопки восстановления
расширяли редактор на **222 px** за границу телефона. Сообщение и кнопки
теперь переносятся по доступной ширине, текст кнопок может занимать несколько
строк. На телефоне сохраняется минимальная высота действий 44 px.

На 320×567, 390×320, 641×768 и 1366×768 переполнение редактора, тела и
сообщения после исправления — **0 px**, текст кнопок не обрезается.
Проверка выполнена применением нового CSS к уже воспроизведённому локальному
конфликту. Механизм синхронизации, разрешения конфликтов и скачивания копий
не менялся; восстановление рабочих версий не выполнялось.

## Приёмка

Изолированное пространство Layout QA, внешние интеграции отключены.
Production-сборка Vite preview, Chromium с закреплённой полосой прокрутки,
чтобы учитывать более узкую рабочую область Windows.

- 42 состояния редактора: Markdown, блоки, обычный текст, чтение в редакторе
  и возврат к исходнику; RU / светлая / обычная плотность и EN / тёмная /
  компактная плотность.
- Размеры 320×567, 390×844, 390×320, 640×768, 641×768, 844×390, 1024×768,
  1366×768; дополнительно четыре состояния сообщения о конфликте.
- Длинное название, длинная строка кода, таблица, многочисленные разделы.
  Во всей матрице переполнение редактора, тела и панели — 0 px.
- Полный список форматов открывается с клавиатуры и помещается в экран.
  Проверены форматирование, меню инструментов, 16 последовательных Tab
  внутри диалога, Escape и восстановление высоты после смены ориентации.
- Смена формата сохраняет исходный Markdown. Реальные изменения
  синтетического текста в Markdown и блоках подтверждены чтением API;
  сохранённая заметка прочитана в новом браузерном контексте. Другие разделы
  и длинная строка кода сохранены; исходный текст прогона восстановлен.
- Свойства и перемещение среди 27 папок на 320 px помещаются по ширине;
  диалоги закрыты без изменения свойств и назначения.
- Пользователь viewer читает заметку без действия редактирования.
- Пять проверок axe WCAG A/AA прошли без нарушений в изменённых панелях.
  Исключений JavaScript в итоговом сценарии нет.

19 серверных тестов блоков, Markdown, перемещения и истории прошли.
ESLint, Prettier, CSS-переменные, сборка и бюджет начального JavaScript
проверены. Размеры телефонов эмулируются; физическая экранная клавиатура
и скринридеры не проверялись.
