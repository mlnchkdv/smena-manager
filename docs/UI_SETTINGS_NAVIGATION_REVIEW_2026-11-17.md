# Аудит навигации настроек и пустой личной работы

Дата: 17 ноября 2026. Исходная опубликованная версия: `7539ab68`.

## Авторизованный осмотр

Повторно подтверждены опубликованные фильтры задач: ширина 560 px на
1366×768 и 304 px на 320×567, без горизонтального переполнения.
Проверены настройки переноса данных, загруженный список резервных копий,
раскрытые параметры независимой копии и KMS Brain, инструменты библиотеки
и диалог типов заметок. Рабочие копии не создавались, файлы не выгружались
и не импортировались. Два поля типа добавлялись только в локальный черновик
диалога, затем он закрыт кнопкой отмены; типы не сохранялись.

На узком телефоне поля типа занимают 278 px, имеют высоту 44 px и не
переполняют окно. Параметры переноса также помещаются по ширине.
Сохранённые настройки, разрешения и рабочие материалы не изменены.

## Навигация настроек

Постоянные поиск и выбор раздела занимали две строки: **113 px** на 320 px.
Они размещены в одном ряду высотой **61 px**, освобождая 52 px для страницы.
Поиск остаётся непосредственно доступным. Его короткая подсказка — «Поиск» /
«Search»; полное доступное имя сохранено. Выбор раздела сохраняет полный
список и полное название выбранного раздела в подсказке.

Компоновка учитывает как ширину окна, так и ширину рабочей области.
На широком ноутбуке остаётся отдельная колонка настроек. При вводе запроса
сохраняется выделенный режим результатов на всю ширину; очистка возвращает
обычную страницу и оставляет фокус в поиске.

Найдена отдельная проблема короткого мобильного экрана: на 390×320 список
результатов оканчивался на y=310, нижняя навигация начиналась на y=263.
Последний результат перекрывался, обычное нажатие не проходило. Область
поиска теперь резервирует фактическую высоту нижней навигации; последний
результат доступен прокруткой и нажатием.

## Ошибка главной — `e6a8af74`

В опубликованном пространстве переход на главную показывал «Не удалось
открыть раздел». Локально воспроизведено исключение `Unknown count kind: task`:
пустая вкладка личной работы выводила число открытых задач команды, но
словарь счётчиков не содержал форм для задач.

Добавлены английские и русские формы. Проверены 0, 1, 2, 5, 11, 21 и 22,
а также реальное открытие главной с шестью открытыми тестовыми задачами
при пустой предстоящей личной работе на двух языках и двух размерах.
Исправление отправлено отдельным коммитом; задачи и назначения не менялись.

## Приёмка

Отдельная production-сборка и изолированный Layout QA с отключёнными
внешними интеграциями. Проверены 34 состояния настроек:

- RU/light/comfortable и EN/dark/compact;
- 1366×768, 1101×768, 1100×768, 1024×768, 900×768, 641×768, 640×768,
  390×844, 320×567 и 390×320;
- смена размеров без перезагрузки, переход через выбор раздела, поиск,
  отсутствие результатов, очистка, нажатие последнего результата,
  переход по результату с клавиатуры, возврат к широкой колонке;
- шесть проверок axe по WCAG A/AA без нарушений;
- отдельный участник с правом просмотра: скрытые административные разделы
  отсутствуют в выборе и поиске; прямой запрещённый маршрут показывает
  сообщение о требуемых правах без переполнения.

Прошли четыре состояния главной и десять целевых серверных тестов.
Материалы и права тестового пространства не изменены; язык, тема и плотность
менялись только у изолированных тестовых профилей. Проверены сборка Vite,
ESLint изменённого JS, Prettier и CSS-переменные. Начальный JavaScript —
399,8 KiB при бюджете 600 KiB. Общий серверный набор и приёмка трёх браузеров
выполняются в CI после push.

Физические телефоны, экранная клавиатура и скринридеры не проверялись.
