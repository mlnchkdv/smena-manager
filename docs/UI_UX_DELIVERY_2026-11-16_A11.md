# Внедрение A01–A11 — 16 ноября 2026

Основание: [повторный аудит](UI_UX_FOLLOWUP_AUDIT_2026-11-15.md). Каждая правка публикуется отдельным коммитом. Production-проверки отделяются от локальных, рабочие материалы команды не используются для тестовых изменений.

## Выполнено

- A03: активное назначение и действие переноса закреплены в каталоге, на телефоне — над нижней навигацией с учётом видимого viewport. Дублирующая панель выбранных файлов скрыта только на время переноса, последним карточкам оставлено место; отмена возвращает исходную папку.

- A02: панель переноса показывает полный путь назначения и количество файлов. Представление и действие используют одну проверку владельца, пространства и актуального права редактирования; недоступная цель отключает перенос и предлагает выбрать назначение заново.

- A01: только заголовок рамки располагается над карточками. Заливка и границы рамки остаются под содержимым; заголовок больше не обрезается перекрывающей крупной карточкой. Клавиатурный выбор в списке сохранён.
