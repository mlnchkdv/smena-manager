## Delivered during this audit / Уже внедрено

1. **Project Whiteboard / Холст проекта.** Separate tab, text cards, frames, references to existing notes/tasks/projects/bookmarks/files, labeled connectors, pan/zoom, title dragging, group movement, keyboard movement, local undo/redo, outline mode and JSON export. Material names resolve from current authorized data, rather than copying private content into the canvas.
2. **Simplified graph / Упрощённый граф.** Compact colored nodes and thin lines; labels appear on selection/hover. Filters, material navigation and the accessible list remain available. Personal preference is saved.
3. **Knowledge Display / Меню «Вид».** Compact, left-aligned groups for layout, tools and saved searches; explicit close, internal scroll and disabled folder layout when folders are hidden. Folder visibility no longer closes the menu.
4. **Personal sidebar / Личное меню.** Hide/reorder entries within Personal and Workspace, toggle counters and project/team shortcuts. Available through Appearance and the workspace heading shortcut. Settings, account, Archive and mobile quick navigation remain available. Saved per user in the current workspace.
5. **Graph physics / Физика графа.** Opt-in bounded CoSE settling; off freezes current positions, dragging restarts settling when enabled. Reduced-motion preference is respected. Coordinates do not write to shared workspace data.
6. **Help / Помощь.** Removed from the sidebar footer and placed under Settings → Help & resources, including keyboard/command tools, feature guidance and legal links. Accessible to ordinary members.

## Developer handoff / Контекст для разработки

**RU.** `project.whiteboard` имеет версию 1, массивы nodes/edges; до 200 карточек и 400 связей, размер JSON до 350 000 символов. Материальная карточка хранит ссылку `kind:id`, без кеширования названия/текста. Валидация: `src/shared/project-whiteboard.js`, defaults/schema, серверная policy; UI: `src/views/project-whiteboard.js`, lazy actions `src/features/project-whiteboard.js`, локальное состояние `src/core/whiteboard-state.js`. Новый material target проверяется по текущим правам; удалённая/закрытая ссылка отображается как недоступная. Автоматические связи project→material попадают в граф. Локальные коннекторы холста не создают ручные глобальные связи.

**EN.** Whiteboards inherit project access. The version-1 project field contains up to 200 nodes/400 edges with a 350,000-character JSON budget. Material nodes store only `kind:id`; current readable entities supply labels. The shared validator, workspace schema/defaults and server policy enforce persistence boundaries. The renderer/actions/state modules above own canvas interaction. New targets require current read access; missing/revoked targets show an unavailable placeholder. Automatic project-to-material usages appear in Graph; local canvas connectors do not create global manual relations.

**RU.** `prefs.sidebar` — валидированная JSON-строка, описанная в `sidebar-preferences.js`; применяется через существующий personal-settings API. `graphSimple` и `graphPhysics` — булевы личные настройки. Физика ограничена 300 итерациями и окном анимации до 2,5 секунд; это автоматическое распределение после включения/перетаскивания, а не бесконечная симуляция. Выключение фиксирует текущее расположение в открытом графе; отдельного долговременного хранения координат пока нет.

**EN.** `prefs.sidebar` is a validated JSON string described in `sidebar-preferences.js`, saved through the existing personal-settings API. `graphSimple` and `graphPhysics` are personal booleans. Physics uses up to 300 settling iterations with a 2.5-second animation cap. It runs on enable/drag, rather than continuously consuming resources; pausing retains current positions in the open graph. Durable coordinate persistence is future work.

Primary design references: [Capacities Whiteboards](https://docs.capacities.io/reference/whiteboards), [Obsidian Canvas](https://obsidian.md/help/plugins/canvas), [JSON Canvas 1.0](https://jsoncanvas.org/spec/1.0/), [Cytoscape CoSE](https://js.cytoscape.org/#layouts/cose). These inform patterns and future interchange work; the current Smena export uses its own schema. / Это ориентиры для сценариев, не заявление о полной совместимости.
