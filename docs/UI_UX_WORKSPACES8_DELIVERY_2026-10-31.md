## Проверка на основном сайте

Проверены RU/EN при фактических CSS-размерах **320×676, 390×845, 767×1024, 1024×767, 1366×767, 1920×1080**.

- Профиль Artem Blohin: все три действия находятся в пределах экрана, внутреннее переполнение кнопок — **0 px**. На 320 px правая граница дополнительного меню — примерно **294 px**. На 320/390/767 px область отметки выполнения — около **44×44 px**; небольшая дробная разница измерений обусловлена масштабом браузера.
- Общее горизонтальное переполнение измеренных страниц профиля и разрешений — **0 px**. Таблица прав на узком экране прокручивается внутри своего контейнера.
- RU: запрос `Фронтенд` находит видимую метку «Фронтенд», отсутствующая метка показывает «Совпадений нет». EN: `Frontend` и `No matches`. Использованы отменяемые пустые черновики; задачи не создавались.
- Запросы `создать задачу` и `create task` находят команду; Enter открывает форму, отмена закрывает её. Русский заголовок группы — «КОМАНДЫ». Авторское название `Frontend сайта` не изменяется.
- Граф: на EN desktop и RU 390 px открыт навигатор, введён `Frontend`, фокус перемещён на результат. После завершения чтения связей запрос и фокус остаются на месте. В AX-наблюдениях состояние «Загрузка связей…» сменилось пустым списком связей без закрытия поиска. Дополнительно проверены поиск и размеры меню на 320/390/767 px.
- Вкладки участников и профиля переключались клавишами End/Home и Enter. Выбранная вкладка и подпись связанной панели обновляются, фокус остаётся на вкладке.
- Таблица прав проверена на обоих языках: новых обещаний оплаты/удаления нет, доступ гостя только на чтение, создание своего пространства отделено от общих настроек. Опасные действия не запускались.
- При обновлении сборки один лениво загружаемый экран потребовал штатное действие Update and reopen; после обновления проверка продолжилась, сессия и адрес сохранились. Это наблюдение о проверке во время публикации, а не утверждение о проверке всех возможных ошибок обновления.

Production-сессия принадлежит текущему администратору Dmitriy. Ограниченный экран обычного участника проверен локально, без входа в чужой аккаунт. Данные задач, заметок, файлов, связей, членство и права команды в production не изменялись. Временные меню/формы закрыты, граф снят с выбранного материала. В конце возвращены русский язык, исходный размер вкладки **691×755 CSS px** и профиль Artem Blohin; отображается «Сохранено».

## Локальная проверка

- **548/548 серверных тестов** прошли. Новые проверки охватывают локализованные имена и алиасы, фактическую функцию меню меток, исполняемые команды палитры, сохранение поиска/каретки/варианта по значению, отказ от восстановления неактивного меню, ограничения настроек для участника/гостя, контекстную таблицу прав и ручную клавиатурную активацию вкладок.
- Итоговый Chromium-прогон — **2/2**, около **5,6 минуты**. Расширен существующий `audit8-interactions.spec.js`: RU/EN, семь размеров **320, 390, 767, 844×390, 1024, 1366, 1920 px**, локализованный поиск, выполнение команды, профиль и семантика вкладок, области касания. Ответ связей графа намеренно задерживается, затем завершается при открытом поиске: запрос и фокус не теряются.
- Нажатие по краю увеличенной области галочки проверено на локальной задаче: статус сохраняется, карточка не открывается. Статус затем возвращается обратно.
- `member-workspaces.spec.js` проверяет реальный локальный вход обычного участника, создание своего пространства, сохранение/обновление его настроек, неизменность роли в исходном пространстве и объяснение недоступности исходных настроек. Проверены оба языка и размеры формы 320/390/767/1366 px.
- Итоговая сборка, ESLint, Prettier, UI-токены и `git diff --check` прошли. Начальный JavaScript — **599,3 KiB**, бюджет **600 KiB**. Предупреждение Vite о чанке больше 500 kB сохраняется; запас бюджета небольшой.

После успешного первого расширенного прогона итоговый сценарий повторён на финальных стилях планшетных областей нажатия. Единственное начальное падение нового сценария было связано с тестовым перехватом: запрос связей передаётся серверу как `mode=view` с `includeArchived`, а не как `mode=connections`. Условие фикстуры исправлено, оба полных прогона после этого прошли. Ошибки приложения не скрывались увеличением тайм-аутов.
