## Проверки кода и изолированных сценариев

- `npm run lint` — успешно.
- `npm run check:tokens` — успешно, все CSS-переменные разрешаются.
- Prettier для изменённых исходников и тестов — успешно.
- `npm run test:server` — **537/537**. Включены проверки реальных UI-обработчиков с изолированными границами store/DOM: независимые правки, конфликт и его повторный просмотр, подтверждение нужных полей, восстановление черновика после тайм-аута и сохранение идентификатора операции. Асинхронное подтверждение проверено на задержку, двойной запуск, отказ и повтор.
- Существующий Chromium-сценарий `shared content, files, settings, and backups persist through core workflows` — **1/1**, включая новые проверки формы. Проверки записи, корзины и копии выполнялись в локальном изолированном пространстве, без Google/Gmail/Redis credentials.
- Существующий `core task flow and responsive shell work across browser engines` — **2/2**, Firefox и WebKit. Это приёмка базового сценария и адаптивной оболочки, а не заявление о полном тестировании всех возможностей в этих движках.
- `npm run build` — успешно. Initial JavaScript: **594.1 KiB / 600 KiB**. Предупреждение Vite о чанках больше 500 kB остаётся; бюджет начальной загрузки не превышен.

Дополнительный `npm run check:ergonomics` остановился до приёмки с `ERR_CONNECTION_REFUSED`: отдельная фикстура Layout QA на портах 5194/3194 не запущена. Этот запуск не считается пройденным. Команда не направлялась в production; её полную матрицу тем/плотности не заменяют результаты выше. `npm run check:ui` в данном проходе не запускался.

## Проверка основного сайта

Проверена опубликованная версия на <https://smena-manager.vercel.app/>. Перед последним проходом `app-version.json` подтвердил `fcab09baab3cb2758733b65acee1515e5e110979`, содержащий все изменения приложения этого пакета.

Для общей шапки и горизонтального переполнения проверены **17 разделов × 6 ширин × 2 языка = 204 сочетания**. CSS viewport: 320 × 676, 390 × 845, 767 × 1024, 1024 × 767, 1366 × 767, 1920 × 1080. Дополнительно проверены короткие окна 567 × 320 и 844 × 390. Это проверки компоновки; они не являются 204 сценариями записи данных.

В проверенной сетке шапка имеет высоту около 53 px на телефонах и 46 px на больших экранах. Корневая страница не имеет горизонтального переполнения. Целевые сценарии проверены подробнее:

- **Настройки RU/EN:** исходная кнопка сохранения отключена; несохранённый ввод явно обозначен, включает кнопку; отмена возвращает исходное значение. Тестовые строки не сохранялись в рабочем пространстве.
- **Подтверждение очистки RU/EN:** полное локализованное предложение и доступная подпись; подтверждающая кнопка отключена до ввода. Операция не запускалась.
- **Роли:** русский переключатель показывает «Администратор», английский — `Administrator`.
- **Создание RU/EN:** закрытие и повторное открытие восстанавливает обозначенный черновик; «Начать заново» очищает его. Проверены края и footer формы на шести размерах и коротком окне. Пространства не создавались.
- **Календарь:** на 1024/1366 × 767 последняя неделя помещается в рабочую область; перепроверены месяцы с четырьмя, пятью и шестью неделями. Дополнительные месяцы просмотрены без изменения задач; дата возвращена к текущему месяцу.
- **Граф RU/EN:** готовое полотно и управление измерены после загрузки, а не на placeholder. На 1366 × 767 содержимое укладывается в доступные 722 px. На 390 × 845 обычная сцена заканчивается примерно на y=776, выше нижней навигации y=788. Проверены имя фильтра без выбора и с одним фильтром (`Filters: 1`), раскрытие панели, список, выбор материала, фокус и выход из него. Фильтры и выбор после проверки сняты.
- **Папки RU/EN:** на 844 × 390 действия и строки имеют цели около 44 px; меню помещается в viewport, названия действий локализованы. Переименование открыто для проверки и отменено без записи.

Изменять материалы, права и состав команды для приёмки не потребовалось. Очистка/архивирование рабочего пространства и реальные конкурентные записи двух администраторов не выполнялись: эти ветки проверены изолированными тестами обработчиков. В production проверены их доступные формы и подписи.

Русский язык и исходный viewport **1600 × 900** возвращены. Итоговая вкладка — `/smena/knowledge`, открытых диалогов нет, статус «Сохранено». После заключительного обновления авторизованная сессия сохранилась.

Локальные доказательства: `output/playwright/audit10-delivery-2026-10-29/`, в том числе `measurements.json`, `server-tests.log`, `build.log`, RU/EN-скриншоты. Они не включены в Git, поскольку содержат интерфейс рабочего пространства. Скриншоты и браузерное изменение viewport не подтверждают физические Safari/iOS/Android, экранную клавиатуру или фоновое возобновление передач.
