# Холст: вставка, загрузка и мобильные просмотры — 18.11.2026

Продолжение аудита изображений, сайтов и PDF. Проверена опубликованная авторизованная страница и кандидат изменений в отдельном пространстве Layout QA. Результаты и границы проверки: [JSON](UI_CANVAS_INPUT_REVIEW_2026-11-18.json).

## Исправления

- Ctrl/Cmd + V получает изображения из системного буфера, ссылки HTTP(S), обычный текст и выделение карточек Smena. Системный буфер имеет приоритет над старым внутренним выделением. При вводе в поле или открытом диалоге команды холста не вмешиваются.
- PNG/JPEG/GIF/WebP/AVIF и PDF можно перетащить на холст или список. Место отпускания переводится в координаты холста; пачка располагается сеткой с допустимыми координатами. Появляется подсказка зоны добавления.
- Все способы загрузки используют существующую очередь, проверку файлов, выбор проекта и подтверждение загрузки. До 12 файлов по 20 МиБ. Пустые/неподдерживаемые/слишком большие файлы отсеиваются до загрузки. Лимит 200 карточек проверяется заранее.
- Ссылки и текст сначала открываются как редактируемый черновик. Для телефона добавлена команда «Вставить ссылку или текст» в меню добавления. HTML из буфера остаётся буквальным текстом.
- Меню добавления сохраняется при обновлении данных, прокручивается внутри доступной высоты и располагается выше нижней навигации.
- При нескольких карточках одного файла кэш учитывает видимость каждой карточки отдельно. Уход с холста и смена области доступа освобождают превью, как прежде.
- Фоновые страницы PDF рендерятся до 640×800 без извлечения ненужного текста; отдельный просмотр сохраняет прежние пределы 1280×1600 и текст страницы. Это уменьшает затраты памяти на изображения страниц. Повтор после ошибки восстанавливает превью.

## Проверка

128 состояний: 80 RU/EN, светлая/тёмная тема и обычная/компактная плотность; ещё 48 проверок меню, вставки и медиа на восьми размерах от 320×567 до 1366×768, включая короткий экран 390×320. Горизонтальное переполнение: 0 px. Проверок доступности WCAG A/AA: 6, нарушений: 0. Ошибок выполнения страницы: 0.

Пройдены 62 серверных теста холста, ESLint, Prettier, проверка CSS-токенов и сборка Vite. Проверены реальная вставка PNG из системного буфера, выбор PNG/PDF системным диалогом, загрузка через очередь, перетаскивание, чтение после перезагрузки, листание PDF, переход в полный просмотр с текущей страницы, текст PDF, отмена вставки и неизменность данных при просмотре пользователем без права редактирования.

На опубликованном сайте проверены авторизованный холст, меню и формы на ноутбуке и телефоне. Автоматическая передача тестовых файлов в опубликованную вкладку остановлена ограничением расширения браузера на локальные file URL. Настройки безопасности не менялись, тестовые записи в рабочем пространстве не создавались. Полный цикл записи файлов проверен отдельно в Layout QA. Проверка отображения сайта локально использует защищённый просмотр и очищенный HTML от существующего серверного обработчика; произвольные активные iframe не добавляются.

Материалы проверки находятся в output/playwright/canvas-audit18/: followup-*.log, followup-pdf-phone.png и followup-media-laptop.png. Сборка для теста: npx vite build --outDir .data/canvas-audit18/dist. Серверные проверки: node --test tests/server/_whiteboard_.test.js. Публикация идёт через стандартную CI-проверку main; итог развёртывания фиксируется в GitHub Actions.

## Следующие полезные возможности

1. Извлечение выбранных страниц PDF в отдельные карточки с ссылкой на исходный файл и сохранением прав доступа. Это даст возможность сравнивать страницы рядом.
2. Обрезка и поворот изображений с возможностью вернуть оригинал.
3. Комментарии и отметки на конкретной карточке/странице, затем поиск по таким обсуждениям.

Приоритеты выбраны по существующим сценариям Smena и примерам [быстрого добавления материалов Miro](https://help.miro.com/hc/en-us/articles/360017731233-Ways-to-add-content), [работы с файлами и извлечения страниц](https://help.miro.com/hc/en-us/articles/360017731013-Uploading-files-to-boards). Эти три возможности ещё не реализованы в данном изменении.
